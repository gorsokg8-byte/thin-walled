# Механика тонкостенных конструкций — приложение для подготовки к СММ

Локальное веб-приложение: теория с выводом каждой формулы, сверка лекций с книгами, калькуляторы, задачи с пошаговой проверкой, тесты, карточки с интервальным повторением.

## Как открыть

- Проще всего: двойной щелчок по `index.html` (работает без интернета и без сервера).
- Через сервер (если браузер что-то блокирует): `python -m http.server 8765 --directory D:/cloude/thin-walled-app`, затем открыть http://localhost:8765.

Прогресс, карточки и введённые значения калькуляторов хранятся в браузере. Перенос на другое устройство — «Настройки и прогресс» → «Скопировать прогресс», затем на другом устройстве вставить текст в то же поле → «Загрузить из вставленного текста».

## На iPhone

Приватная страница на claude.ai: https://claude.ai/artifact/SEoPVwuqkfoYo487ZHxNzH (открывается после входа в свой аккаунт Claude). Обновление после правок: `python tools/build_artifact.py`, затем переопубликовать `dist/index.html` с файлами из `dist/files.json`. Сканы книг в телефонной версии не открываются (они только на ПК).

## Свой сайт на GitHub Pages (без Claude, работает офлайн)

1. Завести бесплатный аккаунт на https://github.com.
2. Создать репозиторий: «New repository» → имя `thin-walled` → Public → без README → «Create repository».
3. Привязать и отправить (при первом `git push` откроется окно входа в GitHub):
   `git remote add origin https://github.com/ЛОГИН/thin-walled.git`, затем `git push -u origin main`.
4. В репозитории: Settings → Pages → Source «Deploy from a branch» → Branch `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт: `https://ЛОГИН.github.io/thin-walled/`.
5. На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“». После первого открытия работает без интернета.

Обновление сайта после правок:
`python tools/build_pages.py` (новая версия офлайн-кэша) → `git add -A` → `git commit -m "Описание"` → `git push`.

Сайт GitHub Pages виден всем, у кого есть ссылка (сканы книг из `_work/` в репозиторий не попадают).

## Структура

| Путь | Что там |
| --- | --- |
| `index.html`, `css/app.css` | страница и стили |
| `js/core.js` | общие функции: формулы (KaTeX), хранилище, прогресс, интервальное повторение |
| `js/views.js`, `js/app.js` | страницы и маршрутизация |
| `js/plot.js` | графики (SVG) |
| `js/calcs/*.js` | калькуляторы: безмоментная теория, краевой эффект, сопряжение, функции f и K |
| `content/course.js` | программа курса и источники |
| `content/tNN-*.js` | темы: блоки теории, формулы с выводами, тесты, карточки, задачи |
| `tools/` | скрипты: рендер страниц PDF/DjVu, OCR |
| `_work/` | (не в git) сканы страниц и OCR-текст книг и конспектов |

## Как устроена тема

Формула — блок `{ t: 'f', id, name, no, tex, deriv: [...], src: [...], verified, diff }`:
- `deriv` — шаги вывода (кнопка «Вывод»);
- `src` — ссылки вида `bid:165 (3.96)` (Бидерман, страница книги), `lec7:19` (страница PDF конспекта); открывают скан страницы;
- `verified` — с чем сверено;
- `diff` — расхождение лекции и литературы (собираются на странице «Сверка лекций с книгами»).

Страница Бидермана в книге = номер файла `_work/biderman/pNNN.png` + 1.
